# Company Profile UKM-O Catur & Bridge

Website profil UKM Catur & Bridge merupakan sebuah platform informasi digital yang dikembangkan untuk memperkenalkan organisasi Unit Kegiatan Mahasiswa (UKM) Catur & Bridge kepada mahasiswa dan masyarakat kampus.

Website ini bertujuan untuk memberikan informasi mengenai profil organisasi, sejarah, visi dan misi, kegiatan, fasilitas, serta berbagai aktivitas yang diselenggarakan oleh UKM Catur & Bridge.

Melalui website ini, diharapkan mahasiswa dapat mengenal lebih dekat UKM Catur & Bridge, mengetahui berbagai kegiatan organisasi, serta memperoleh informasi bagi mahasiswa yang tertarik untuk bergabung dan mengembangkan minat maupun bakat di bidang olahraga catur dan bridge.

## Tujuan
- Memperkenalkan UKM Catur & Bridge kepada lingkungan kampus.
- Menyediakan informasi mengenai profil dan sejarah organisasi.
- Menampilkan kegiatan dan aktivitas organisasi.
- Menjadi media publikasi dan dokumentasi organisasi.
- Memudahkan mahasiswa dalam memperoleh informasi mengenai UKM Catur & Bridge.

# Website UKM Catur & Bridge

Website UKM Catur & Bridge merupakan platform informasi digital yang bertujuan untuk memperkenalkan organisasi Unit Kegiatan Mahasiswa (UKM) Catur & Bridge kepada mahasiswa dan lingkungan kampus.

Website ini dikembangkan sebagai media informasi, publikasi kegiatan, serta dokumentasi organisasi.

## Langkah-Langkah Pengembangan

1. **Persiapan Proyek**
   - Menentukan tujuan dan konsep website.
   - Menentukan struktur halaman website.
   - Menyiapkan kebutuhan desain dan aset.

2. **Pembagian Tugas**
   - Membagi pekerjaan berdasarkan bagian atau halaman website.
   - Menentukan tanggung jawab masing-masing anggota tim.
   - Menentukan target penyelesaian.

3. **Proses Pengembangan**
   - Membuat struktur HTML.
   - Mengembangkan tampilan menggunakan CSS dan Bootstrap.
   - Menambahkan interaksi menggunakan JavaScript.
   - Mengintegrasikan seluruh bagian website.

4. **Pengujian Website**
   - Memeriksa fungsi setiap halaman.
   - Memastikan tampilan responsif.
   - Memperbaiki kesalahan atau bug.

5. **Penyelesaian**
   - Melakukan evaluasi akhir.
   - Memastikan seluruh fitur berjalan dengan baik.
   - Melakukan publikasi website.

## Cara Menjalankan Website

### Persyaratan
- Git
- Web Browser (Google Chrome, Firefox, dan sebagainya).
- Visual Studio Code (disarankan).

### Langkah Menjalankan

1. Clone repository:

   ```bash
   git clone URL_REPOSITORY
   ```

2. Masuk ke direktori proyek:

   ```bash
   cd nama-folder-proyek
   ```

3. Buka folder proyek menggunakan Visual Studio Code.

4. Jalankan file `index.html` melalui browser atau menggunakan ekstensi Live Server.

5. Website siap diakses secara lokal.

## Aturan Kerja Tim (Team Rules)

Untuk menjaga keteraturan dan menghindari konflik selama proses pengembangan, seluruh anggota tim wajib mengikuti aturan berikut.

### A. Pembagian Tugas
- Setiap anggota memiliki tanggung jawab masing-masing.
- Anggota wajib mengerjakan bagian yang telah ditentukan.
- Tidak mengubah pekerjaan anggota lain tanpa koordinasi.

### B. Aturan Penggunaan GitHub
- Setiap anggota wajib melakukan clone repository sebelum mulai bekerja.
- Gunakan branch masing-masing untuk mengembangkan fitur.
- Jangan melakukan perubahan langsung pada branch `main`.
- Lakukan commit secara berkala.
- Gunakan Pull Request sebelum menggabungkan perubahan ke branch `main`.
- Pastikan perubahan tidak menimbulkan konflik atau merusak bagian lain.

### C. Aturan Penulisan Kode
- Gunakan penamaan file dan folder yang jelas.
- Tulis kode dengan rapi dan konsisten.
- Hindari menghapus atau mengubah kode anggota lain tanpa izin.
- Berikan komentar pada bagian kode yang membutuhkan penjelasan.

### D. Komunikasi dan Koordinasi
- Setiap kendala wajib dikomunikasikan kepada tim.
- Diskusikan perubahan besar sebelum diterapkan.
- Saling membantu apabila terdapat kesulitan teknis.
- Berikan informasi mengenai progres pekerjaan secara berkala.

### E. Tanggung Jawab Anggota
- Menyelesaikan tugas sesuai kesepakatan.
- Melakukan pengecekan sebelum mengirim perubahan.
- Menjaga kualitas dan konsistensi website.
- Bertanggung jawab terhadap bagian yang dikerjakan.
